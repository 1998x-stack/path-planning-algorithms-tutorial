HOW THE COURSE WORKS

每一步都要回答一个更具体的问题。

先观察一张地图，定义机器人能到达的状态；再把连续问题离散化或采样，搜索候选路线；最后检查碰撞、曲率、时间和控制误差。图示、推导和最小代码会对应同一个问题，避免公式与实现脱节。
